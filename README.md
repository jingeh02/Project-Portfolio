## 🕺 AI-Based Dance Pose Evaluation System

**Period:** 2017  
**Domain:** AI / Computer Vision / Education  
**Role:** Software / AI Developer

I developed an educational application that evaluates a dancer's body pose from camera input rather than relying solely on human testers. The system compares detected pose landmarks and joint angles with teacher-defined reference poses, then produces a score between **0 and 10**.

### Processing Pipeline

```text
Camera Input
    ↓
OpenPose / Pose Detection
    ↓
Body-Pose Landmarks
    ↓
Joint-Angle Calculation
    ↓
Comparison with Reference Poses
    ↓
Evaluation Score (0–10)
```

**Technologies:** Python, Qt, OpenPose, OpenCV, computer vision, pose estimation and algorithm development.

The application was built for Windows using Qt, with a structure that could support further cross-platform development. This project is a relevant example of turning visual input into measurable, application-level decisions.

## 🧵 Embroidery Machine Control System

**Period:** 2016  
**Domain:** Manufacturing / Machine Integration  
**Role:** Software Developer · System Designer

I worked on a mobile control/monitoring solution that communicated with a low-level device associated with an embroidery machine through Bluetooth.

The core challenge was not simply establishing Bluetooth communication. It was **processing and displaying a large volume of machine-status data in real time**, including the current sewing status. I addressed the visualization challenge using **OpenGL**.

### System Concept

```text
Machine / Low-Level Device
          ↓
 Bluetooth Communication
          ↓
    Mobile Application
          ↓
 Real-Time Status Processing
          ↓
    OpenGL Visualization
```

**Technologies:** Mobile development, Bluetooth communication, OpenGL, real-time data processing and visualization.

**Why it matters:** This is a concrete example of software working with a physical machine, where responsiveness and efficient rendering were central engineering concerns. The description reflects my software and integration contribution; it does not imply that I designed the machine's PCB or electrical hardware.

```text

             ↓
```

I do not consider the first fix to be the end of a difficult engineering task. I try to understand what else could prevent the solution from working, address those issues, and keep the project moving.
